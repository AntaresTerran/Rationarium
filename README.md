# Rationarium 🏛️

> **Das kaiserliche Rechenbuch für Anno 117: Pax Romana**  
> Ein modernes, echtzeitfähiges Second-Screen-Dashboard zur Überwachung von Produktionen, Bilanzen, Arbeitskräften und Ressourcen über die offizielle Anno 117 Named Pipe (`\\.\pipe\anno117`).

---

## 📖 Dokumentation & Konzept

Das ausführliche Architektur-, Schnittstellen- und Design-Dokument befindet sich in:
👉 **[DESIGN.md](DESIGN.md)**

Dort sind alle technischen Details beschrieben:
* Das Binärprotokoll der Anno 117 Named Pipe (`\\.\pipe\anno117`)
* Die Architektur von Backend, WebSocket-Streamer und Frontend
* Das Konzept für die Standalone `.exe`-Verteilung (Zero-Configuration für Endnutzer)
* Die modularen Tabs (Reichsübersicht, Produktionsmatrix, Frühwarnradar, Arbeitskräfte)
* Der Leitfaden für Mitwirkende und KI-Entwicklungsagenten
